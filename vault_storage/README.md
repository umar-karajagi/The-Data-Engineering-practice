# DataForge Secure Vault Storage

This directory holds large Jupyter Notebooks (`.ipynb`), PDF manuals, and book archives (100MB to 200MB+).

### Security & DRM Notice:
- Files placed in this folder are **NOT in the public web root** (`public/`).
- External users and browsers **cannot download the raw files directly via URL**.
- The DataForge backend parses these files into interactive, read-only reading views with:
  - Blocked right-click
  - Restricted copying
  - Disabled printing
  - Faint digital watermark

### How to Add Books & Notebooks:
1. Copy or drop any `.ipynb`, `.pdf`, `.md`, or `.txt` files directly into this directory (`dataforge/vault_storage/`).
2. Open the DataForge website in your browser, go to **Library**, and click **"Scan & Sync Vault"**.
3. All files will be automatically indexed into the Master Inventory & Catalog and formatted for the interactive reader!
